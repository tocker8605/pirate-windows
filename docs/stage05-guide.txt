5스테이지 시안 / 편집 안내

구간: 월면 심층 터널 → 금속 터널 → 슈퍼컴퓨터 챔버.
배경: assets/backgrounds/stage05/ (각 1254×1254).
포대·잔해·보스: assets/enemies/stage05/ (투명 PNG).
생성 방식과 전체 프롬프트: assets/backgrounds/stage05/generation-prompts.json.

타임라인: data/stage05.json. 현재 19대의 시험 배치, 82초에 보스 등장.
포대 좌표는 기존 소형 적과 동일한 50×50 기준 좌상단이며 중심은 +25,+25입니다.
예:
{"at": 2, "action": "spawn", "definition_id": 51, "position": [75,-60], "start_exposed": false}
{"at": 7, "action": "spawn", "definition_id": 52, "position": [275,-60], "start_exposed": true}

start_exposed는 불리언 true/false로 작성합니다. false 또는 생략 시 숨김 상태로 등장하고 Y>80부터 0.8초 동안 전개합니다.
완전히 드러나기 전에는 통상탄·레이저 피격 판정이 없습니다. 주인공 기체와의 충돌은 노출 상태와 관계없이 제외합니다.
start_exposed: true는 처음부터 완전 노출 상태입니다. 숫자0/1이나 문자열은 허용하지 않습니다.
포대는 이동 pattern 대신 배경의 실제 누적 이동량을 따릅니다.
배경 바로 위에 그리며 다른 기체와 탄환 아래에 표시합니다.
파괴 시 판정 없는 잔해를 남기고 스크롤을 따릅니다. 화면 밖 또는 스테이지 전환 시 제거합니다.

초기 밸런스 (data/enemies.json에서 편집):
51 autocannon_turret: HP75, 양쪽 기관포 0.18초, 탄속210px/s.
52 energy_turret: HP110, 분홍 에너지 구체 1.2초, 탄속160px/s.
53 missile_turret는 정의·타임라인·이미지에서 삭제했습니다.
95 boss_stage5: HP2000, 전선으로 바닥에 연결된 메카닉 상체, 이동·공격 없음.
141/142: 좌우 게틀링 팔. 좌우는 동일 이미지를 반전합니다. 143/144: 좌우 미사일 날개를 복원했습니다.
파츠는 각 HP400, 점수0으로 임시 배치되어 독립 파괴 가능합니다. 공격 패턴은 미정입니다.
보스 도착 시 배경 정지. 보스 점수는 미정으로 현재0입니다.
5면 음악은 임시로 기존 bgm04를 사용합니다.

일반 모드는 4면 다음 5면, 5면 클리어 후 랭킹 입력입니다.
보스러시는 기존 1~4면 구성을 유지합니다.
로직: scripts/ground_turret.gd / 그림: scripts/ground_art.gd.
검증: tests/stage5_ground.gd, tests/render_stage5_ground.gd.
이 작업에서 커밋·푸시·실행파일 빌드는 하지 않았습니다.

해치 문은 팔각형 개구부로 클리핑하며, 파괴 잔해도 같은 팔각형 외곽입니다.
배경 측면 폭을 줄이는 시안은 취소되어 기존 5면 배경을 유지합니다.

5면 표시 크기: 본체100×100(2~4면 기준), 양팔 각50×100, 양날개 각100×50.
부착 위치, 피격 범위와 손상 연기 위치도 표시 크기에 맞춰 조정합니다.


floor_art.hinge_uv는 원본 스프라이트의 관절 중심이며 미러링·종횡비 보존을 적용한 뒤에도 actor.pos와 일치합니다.


5면 보스는 본체·양팔·양날개로 구성됩니다. 팔과 날개 모두 구멍 없는 흰색/보라색 구형 관절이며 날개 위에 팔 순서로 본체를 덮습니다.
관절 중심은 본체의 좌우 소켓(-32,37)/(32,37)에 정렬합니다.
