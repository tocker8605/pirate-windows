5스테이지 시안 / 편집 안내

구간: 월면 심층 터널 → 금속 터널 → 슈퍼컴퓨터 챔버.
배경: assets/backgrounds/stage05/ (각 1254×1254).
포대·잔해·보스: assets/enemies/stage05/ (투명 PNG).
생성 방식과 전체 프롬프트: assets/backgrounds/stage05/generation-prompts.json.

타임라인: data/stage05.json. 현재 19대의 시험 배치, 82초에 보스 등장.
포대 좌표는 기존 소형 적과 동일한 50×50 기준 좌상단이며 중심은 +25,+25입니다.
예:
{"at": 2, "action": "spawn", "definition_id": 51, "position": [75,-60], "start_exposed": false}
{"at": 7, "action": "spawn", "definition_id": 52, "position": [275,-60], "start_exposed": true}

start_exposed는 불리언 true/false로 작성합니다. false 또는 생략 시 숨김 상태로 등장하고 Y>80부터 0.8초 동안 전개합니다.
완전히 드러나기 전에는 통상탄·레이저 피격 판정이 없습니다. 주인공 기체와의 충돌은 노출 상태와 관계없이 제외합니다.
start_exposed: true는 처음부터 완전 노출 상태입니다. 숫자0/1이나 문자열은 허용하지 않습니다.
포대는 이동 pattern 대신 배경의 실제 누적 이동량을 따릅니다.
배경 바로 위에 그리며 다른 기체와 탄환 아래에 표시합니다.
파괴 시 판정 없는 잔해를 남기고 스크롤을 따릅니다. 화면 밖 또는 스테이지 전환 시 제거합니다.

초기 밸런스 (data/enemies.json에서 편집):

141/142: 좌우 게틀링 팔. 좌우는 동일 이미지를 반전합니다. 143/144: 좌우 미사일 날개를 복원했습니다.
게틀링 팔은 각 HP1000, 미사일 날개는 각 HP800이며, 점수0으로 임시 배치되어 독립 파괴 가능합니다. 게틀링 팔은 육각형 분홍탄을 발사하며, 날개는12초 주기로 왼쪽4초 발사/2초 휴식/오른쪽4초 발사/2초 휴식합니다.
본체가 Y>25에 도달하면 배경이 부드럽게 감속 정지합니다. 보스 점수는 미정으로 현재0입니다.
5면 음악은 임시로 기존 bgm04를 사용합니다.

일반 모드는 4면 다음 5면, 5면 클리어 후 랭킹 입력입니다.
보스러시도 1~5면입니다. 5면은 3구간 슈퍼컴퓨터 챔버에서 시작하며 data/stage15.json에서 편집합니다.
로직: scripts/ground_turret.gd / 그림: scripts/ground_art.gd.
검증: tests/stage5_ground.gd, tests/render_stage5_ground.gd.
이 작업에서 커밋·푸시·실행파일 빌드는 하지 않았습니다.

해치 문은 팔각형 개구부로 클리핑하며, 파괴 잔해도 같은 팔각형 외곽입니다.
배경 측면 폭을 줄이는 시안은 취소되어 기존 5면 배경을 유지합니다.

5면 표시 크기: 본체100×100(2~4면 기준), 양팔 각50×100, 양날개 각100×50.
부착 위치, 피격 범위와 손상 연기 위치도 표시 크기에 맞춰 조정합니다.


floor_art.hinge_uv는 원본 스프라이트의 관절 중심이며 미러링·종횡비 보존을 적용한 뒤에도 actor.pos와 일치합니다.


5면 보스는 본체·양팔·양날개로 구성됩니다. 팔과 날개 모두 구멍 없는 흰색/보라색 구형 관절이며 날개 위에 팔 순서로 본체를 덮습니다.
관절 중심은 본체의 좌우 소켓(-32,37)/(32,37)에 정렬합니다.

145 보스 기관포: HP800, 51과 같은 공격. 본체 HP1/3 이하(현재1000)에서만 해치가 열립니다.
146 보스 에너지포: HP800, 52와 같은3연탄을0.24초마다 발사하며8초에 한 바퀴씩 연속 회전. 왼쪽 시계/오른쪽 반시계, 회전 시작 방향은 아래. 본체 HP2/3 이하(현재2000)에서만 해치가 열립니다.
두 파츠는 본체 HP가 기준보다 높으면 해치를 닫고 공격/피격을 중단합니다. 개폐는 기존0.8초 모션이며 닫히는 동안에도 피격되지 않습니다.

보스러시는 본체 등장 시 스크롤을 강제로 정지하지 않습니다. stage15.json의 scroll 이벤트가 목표 속도를 결정합니다. speed0 이벤트 뒤에는 기존 감속률로 정지합니다(30px/s에서는 약0.135초). 5면은 일반/보스러시 모두 본체 Y좌표 조건으로 정지합니다.

5면 본체는 movement_mode: scenery로 바닥의 실제 이동량을 따릅니다. boss_scroll.stop_after_y: 25을 넘는 순간 한 번만 목표 속도를0으로 설정하고, 기존 감속률222.222px/s²로 정지합니다. stage15의15초 정지 이벤트는 제거했습니다. 감속 중에도 본체·부착 파츠·전선·포대는 바닥에 맞춰 이동합니다.

특수 포대145의 논리Y는 본체Y+150,146은 본체Y+300입니다. X는 타임라인 position의 값을 유지하며 본체X를 따라가지 않습니다. attachment.follow_x:false로 지정했고, 기존 팔·날개는 기존처럼 X/Y 부착값을 따릅니다.

날개143/144는 각 미사일 포드 중앙에서 기존 미사일(kind2)을0.12초마다 한 발 발사합니다. 초기Y속도는-33.3333px/s, X는 왼쪽-50~-5px/s/오른쪽+5~+50px/s 범위에서1px/s 단위로 무작위 선택합니다. 이후 기존 미사일과 같은333.3333px/s²의 아래 가속과 최대Y속도500px/s를 사용합니다. 발사 구간은 생성 후 왼쪽[0,4), 오른쪽[6,10), 매12초 반복이며 각 구간 첫 발은0.12초 후입니다. 발사점은 원본 날개 그림(670,660)의 미사일 포드 중심을 힌지/반전에 맞춰 변환한 위치입니다.

양날개143/144는 힌지 기준으로6초 주기 왕복 회전합니다. 왼쪽은0→시계15°→0, 오른쪽은0→반시계15°→0이며3초에 최대 회전,6초에 원위치입니다. 피격/기체 접촉/레이저 판정, 미사일 포드 발사점, 대미지 연기 발생점이 함께 회전합니다. 미사일의 기존12초 교대 공격과 발사 후 속도·가속은 유지합니다.

양팔141/142는 상단 힌지에서10초 주기로 좌우 대칭 왕복 회전합니다. 아래 방향을0°로 왼팔은+30°~-10°, 오른팔은-30°~+10°이며,0°에서 각자 바깥 방향으로 움직이기 시작합니다. 부드러운 코사인 범위 운동을 사용하여 생성 후 약3.333초에 바깥쪽 끝,8.333초에 안쪽 끝을 지나10초에 시작 자세와 운동 위상으로 돌아옵니다. 일반탄/레이저/기체 접촉/연기 발생점/포구가 회전 자세를 공유합니다.
게틀링은0.48초마다 작은 분홍 구체(kind5)6발을 포구 중심의 육각형으로 발사합니다. 묶음 중심은 발사 순간 포구 방향으로200px/s 직진하며 초기 반경10px에서3초 동안30px까지 선형으로 커진 후 유지합니다. 발사된 탄은 이후 팔을 추종하지 않습니다.

보스러시5면에서는141~146의 모든 파츠가 파괴될 때 파워 아이템을 각1개 드롭합니다. 양팔2/양날개2/특수 포대4로 총8개이며 일반 모드에는 추가 드롭이 없습니다. 회전 파츠는 파괴 순간의 자세를 반영한 그림 중심에서 드롭하고, 바닥 포대는 포대 중심에서 드롭합니다. 자동 파괴 시 드롭 정책도 기존1~4면 파츠와 동일하게 유지합니다.
