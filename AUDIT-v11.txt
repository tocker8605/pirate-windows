Pirate II v11 — 3구획 배경 복원 / 적기 선회 애니메이션 재대조

배경의 원본 구조와 복원
  원본 stage1~4 이미지는 각각400x3840입니다. 화면높이H=480 기준으로
  반복 구획2H x3개와 연결부H x2개를 한 장에 중복 저장했습니다.
  진행 방향은 이미지의 아래에서 위입니다.
    구획1: 원본Y2880~3840 / 연결1: Y2400~2880
    구획2: 원본Y1440~2400 / 연결2: Y960~1440
    구획3: 원본Y0~960
  모드1/2/3의 반복 경계는2880/1440/0이며, 반복 시480을 더합니다.
  kind71 이벤트의 모드 변경은 현재 반복을 해제합니다. 화면 전체를 즉시 교체하지 않고
  남은 거리와 연결부를 통과한 뒤 다음 구획에 도착하는 원본 진행을 유지했습니다.

복원한 새 배경의 12개 환경
  1스테이지: 바다 -> 왼쪽 육지/오른쪽 바다의 해안 -> 산림
  2스테이지: 녹색 산악 계곡 -> 설산 -> 산림 능선
  3스테이지: 야간 설산 -> 야간 산악 거점/항구 -> 밤바다
  4스테이지: 지구 대기 -> 우주/성운 -> 회색 지표/착륙장
  일반4스테이지는 모드2/속도2로 시작하므로 첫 구획을 그대로 통과합니다.
  Boss Rush14는 원본 Case14처럼 모드1에서 첫 구획을 반복합니다.
  v10의 누적 거리400~1400에 따른 임의 대기->우주 전환은 제거했습니다.

효율적인 저장/렌더링
  새 배경은12개 구획을 담은1086x1448 단일 아틀라스이며, 구획당362x362입니다.
  같은 그림의 상하 중복본이나8개의 별도 연결 그림은 저장하지 않습니다.
  GPU 셰이더가 현재 위치에 필요한 구획만 샘플링하고 연결부를 공간적으로 혼합합니다.
  연결부는 화면 위에서 진입하여 아래로 이동합니다. 일괄 화면 디졸브가 아닙니다.
  원본의 배경Y는 전환 시점/위상 보존을 위한 가상 좌표로 남아 있습니다.
  이것은 긴 비트맵의 주소가 아니며, background_regions.gd의 공통 메타데이터가
  반복 경계/화면높이와 셰이더 설정을 제공합니다.
  동일한480px 반복 전후에는 타일 위상이 같아 경계 점프가 없습니다.
  미압축 배경 픽셀만 비교하면6,144,000px ->1,572,528px로 약74.4% 감소합니다.
  실제 설치 크기/전체 게임 메모리 측정은 아닙니다. 원본 자료는 보존하여 배포 소스에 남습니다.

적기 애니메이션 대조 및 수정
  v10 새 렌더러의 즉시180도 평면 회전은 원본의 기수 들기 연출과 달랐습니다.
  enemy_pose.gd로 원본 프레임 선택 조건을 분리하고 레거시/새 렌더러가 기준을 공유합니다.
  1/10번: vY>2 / vY>=0 / vY>-4 / 나머지의4단계
    하강 -> 수평 자세 -> 기수 들기/아랫면 -> 상승을 피치 투영으로 연결합니다.
  새 기체의 자세는 틱당 최대18도씩 변화하고 렌더 프레임 사이에는 보간합니다.
  90도 부근에는 날개 모서리를 남기며 기체가 순간적으로 사라지는 것을 방지합니다.
  2/6/7번: 원본의 vY>0 / vY<=0 구분, 좌우 bank 임계값을 유지합니다.
  7번의 원본 시트 주소가 반대 배치인 점도 원본 선택 함수에 반영했습니다.
  8번은 원본처럼 정면에서 날개가 접히고 좌우 bank에서 넓어집니다.
  상승/하강 어느 자세에서도 오른쪽 이동의 기수가 오른쪽으로 기울도록 부호를 맞췄습니다.
  3/4/5/9번의4단계 발광 주기는 원본 애니메이션 시계에 연결했습니다.
  v10에서 일부 기체 전체를 계속 회전시키던 임의 연출은 제거했습니다.
  원본 픽셀 프레임은 레거시 경로에 유지하고, 새 그림은 이 조건과 자세를 투영하여 표시합니다.

상태 관리
  시각 자세는 적의 안정적 ID로 별도 보관하며 위치/속도/판정/발사 벡터를 수정하지 않습니다.
  자세 상태는 생성 시 만들고 틱 중에는 스칼라 값만 갱신합니다. 매 프레임 전체 복사는 없습니다.
  적 제거 시 ID로 즉시 정리하고 로딩/타이틀/스테이지 전환에서 초기화합니다.
  v9의 동적 적/적탄 저장소와 v10의 기본30ms 진행 속도는 유지합니다.
