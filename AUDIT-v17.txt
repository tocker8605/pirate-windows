Pirate II v17 — 주먹/파이어볼/콕핏/타이틀 / 2026-10-26

1스테이지 보스 주먹
  101과102가 같은 그림을 같은 방향으로 그리던 문제를 수정했습니다.
  102를 수평 반전해101과 정확한 좌우 대칭을 이루도록 했습니다.
  각 주먹의 독립 이동·발사·피격 좌표는 유지합니다.

파이어볼
  위로 발사한 후 중력 가속으로 포물선을 그리는 type8을 파이어볼로 표시합니다.
  2보스 중앙 부품113, 일부 적과 최종 보스 분리 부품이 사용하는 같은 탄환에 적용됩니다.
  금속 미사일 표현을 제거하고 주황/노랑 화염·밝은 핵·흔들리는 화염 꼬리와 불씨를 사용합니다.
  꼬리는 현재 속도 반대 방향으로 향하므로 상승/정점/하강 중에도 방향이 이어집니다.
  기존 type8 발사 위치·좌우 속도·초기 상승 속도·중력0.2·피해량은 변경하지 않습니다.
  type2 미사일은 별도 금속 표현을 유지합니다. 효과용 난수만 사용합니다.

주인공
  그림을50x50 ->40x40으로20% 축소하고 기존 중심(25,25)은 유지합니다.
  이동·아군탄 발사·아이템 획득·레이저/실드 앵커는 유지합니다.
  엔진 파티클 위치도 같은 축소 비율로 조정합니다.
  피격 영역을기존 동체 사각형에서 콕핏 중심(앵커+25,+18), 반경4px의 원으로 변경했습니다.
  날개·꼬리·기수는 피격되지 않으며, 실제 콕핏 피격 시 기존 피해·무적 처리를 유지합니다.
  그림/피격 위치는 pilot_geometry.gd의 공통 좌표를 사용합니다.
  비교 이미지의 붉은 원은 확인용이며 실제 게임에는 표시하지 않습니다.

타이틀 순서 정정
  v16에서 지구 배경을 표시하던 시점을 잘못 해석한 부분을 바로잡았습니다.
  Space 입력 전의 첫 화면은 원본 piclog의 검정 배경과 시작 안내 문구입니다.
  Space 입력 후 검정 패널이 왼쪽에서 오른쪽으로 열리며4스테이지 시작 지구가 드러납니다.
  지구 텍스처·셰이더는4스테이지와 동일한 객체를 사용합니다.
  원본의 slide/scroll 카운터, 세로 스크롤과 왼쪽 카메라 이동, 로고/선택 메뉴 연출은 유지합니다.
  메뉴에서 게임으로 이동하면 배경의 카메라 오프셋을0으로 되돌립니다.
  미사용 검정색 키 추출 함수는 제거했습니다.

검증
  콕핏 중심/반경 경계와 날개·꼬리·기수 제외, 실제 적탄 피해/무적, 파이어볼 포물선 유지.
  1보스 주먹의 GPU 좌우 반전 비교와 파이어볼 화염 애니메이션 변화.
  Space 이전 검정 화면, 입력 후 방향성 있는 지구 노출과 원본 메뉴 진행.
  노출된 지구와 같은 카메라 좌표의4스테이지 배경 GPU 픽셀 비교.
  전체 결과와 실행 파일 해시는 VALIDATION.txt 참고.
  원본 폴더/이전 배포본을 보존하며 커밋·푸시는 하지 않습니다.
